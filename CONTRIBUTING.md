# Contributing

This project is in a single-developer, phase-gated MVP sprint. Read `AGENTS.md` and `docs/phase.md`. Keep PRs focused on one phase gate; include tests, docs and evidence. Start with `uv sync --locked`. Run `uv run --locked ruff check .`, `uv run --locked ruff format --check .`, `uv run --locked mypy src tests`, `uv run --locked pytest tests/unit tests/smoke tests/integration/test_source_capture.py -m 'not docker and not live'`, and `uv run --locked python scripts/check_docs.py`. Git must be installed: source tests create and commit synthetic temporary repositories with hooks disabled, then exercise real object capture. They do not execute target scripts. Build with `uv build --wheel`, then run `uv run --locked python scripts/smoke_wheel.py` to check the installed artifact. When Docker is available, run `uv run --locked pytest tests/integration -m docker`; skipped integration checks are not passes. Do not run unknown repository commands on the host or embed tokens into fixtures or logs. Benchmarks must say how many attempted, passed, blocked and skipped.
